O conceito central

Spaces — vários ambientes isolados, estilo Mission Control

Cada Space é um mundo próprio: seus modelos, agentes, chats, tema, hero e badge. Alterne entre eles como quem troca de desktop — sem misturar contextos.

  • Isolamento real — modelos, histórico de conversas e configuração de agente separados por Space.
  • Identidade própria — cada Space tem tema, hero, badge e system prompt configuráveis pela UI.
  • Criados e editados no navegador — nada de editar arquivos à mão para montar um novo ambiente.
  • Troca instantânea — pule de um Space de código para um de escrita ou pesquisa em um clique.

Execução flexível

Do modelo único ao agente com ferramentas

  • 1 modelo — resposta direta, rápida e simples.
  • 2 modelos — revezamento com papéis, ex. rascunho e revisão.
  • Agente + ferramentas — arquivos, RAG e internet quando o Space pede.
Local-first

Roda 100% na sua máquina

Modelos, conversas e configurações ficam no seu computador. Não há conta na nuvem e nada é enviado para servidores externos — sua IA, seus dados, seu controle.

Instalação

Um comando e pronto

O instalador detecta seu sistema operacional e o acelerador disponível, e respeita instalações já existentes.

macOS / Linux
# clone e instale
git clone <repo-url> cylinderui
cd cylinderui
./install.sh

# ou, via Make
make install
Windows (PowerShell)
# clone e instale
git clone <repo-url> cylinderui
cd cylinderui
./install.ps1

# abra a URL do router
# impressa ao final (:8088)

Detecta seu SO e acelerador (Metal, CUDA ou CPU), prepara Python, obtém llama.cpp + llama-swap e respeita instalações existentes. Consulte o guia completo em docs/INSTALL.md para pré-requisitos, portas e troubleshooting.
